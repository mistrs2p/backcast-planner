# Project Context

## Product
Adaptive Backcasting & Goal Execution System.

## Core Problem
Users know a desired future but struggle to translate it into a feasible path from today, taking real calendar constraints and changing capacity into account.

## Core Loop
Goal → Desired Future → Backcast → Plan → Schedule → Execute → Measure → Feedback → Replan.

## Product Principles
- Goal ≠ Plan ≠ Schedule.
- Availability ≠ Capacity.
- Calendar is a time environment, not the source of goal intent.
- Plans are adaptive; goals require explicit revision.
- Deterministic calculations are authoritative.
- AI proposes/reasons; domain validates/enforces.
