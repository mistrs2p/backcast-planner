# Agent System

## Repository Memory
AGENTS.md = rules.
PROJECT_STATE.json = current state.
Task file = current work.
Docs = domain/architecture knowledge.
ADR = decision history.
Progress = historical execution.

## Agent Lifecycle
Read → Inspect → Implement → Test → Debug → Validate → Document → Commit → Push → Next Task.

## Context Discipline
Always-read files must remain compact. Historical context is on-demand.
