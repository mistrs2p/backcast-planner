# Conceptual Model

## Intent Layer
- Goal: user intention.
- Desired Future: destination state.

## Planning Layer
- Current State: snapshot of present reality.
- Gap: distance between present and destination.
- Backcasting: backward reasoning process.
- Strategy: method of movement.
- Plan: selected executable approach.
- Milestone: intermediate measurable checkpoint.
- Outcome: achieved state/result.

## Execution Layer
- Task: actionable unit of work.
- Schedule: placement of task in time.
- Calendar: temporal environment.
- Execution: what actually happened.

## Adaptation Layer
- Measurement: observed data.
- Variance: planned vs actual difference.
- Feedback: explicit or implicit signals.
- Replanning: create a new Plan using updated reality.

## Context
Availability, Capacity, Constraints, Preferences, Habits, Routines, Resources, Dependencies, Buffer.
