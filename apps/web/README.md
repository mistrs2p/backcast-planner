# apps/web — Frontend (Next.js)

Next.js + TypeScript + Tailwind CSS frontend for the Backcasting Goal &
Adaptive Planning System.

Rules (`AGENTS.md` §6):

- Tailwind CSS is the default styling system; do not introduce another CSS
  utility framework.
- Build reusable primitives before feature-specific UI duplication.
- Prefer design tokens and accessible components.

Application code and dependency manifests are introduced by subsequent
EPIC-001 tasks (technology verification, shared contracts).
